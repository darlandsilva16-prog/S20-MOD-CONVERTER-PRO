# Testes com GAR real autorizado

Não há fixtures GAR reais nem testes desta categoria neste checkout. Quando houver uma especificação confiável ou amostra autorizada e não protegida, os testes Java de integração poderão ser adicionados aqui. Mantenha arquivos de amostra fora do Git e forneça-os localmente; os testes devem ser ignorados claramente quando a fixture não estiver configurada. Não use `dataS.gar` protegido.
