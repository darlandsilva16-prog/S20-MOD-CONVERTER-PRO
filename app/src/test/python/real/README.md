# Testes com ZIPs e recursos I3D reais autorizados

Esta suíte não contém fixtures ou testes com ZIPs/mods reais. As amostras extraídas de jogo usadas localmente não devem ser adicionadas ao repositório. Testes reais futuros exigem autorização e condições de uso documentadas, devem receber fixtures por caminho local e permanecer separados de `synthetic/`; não devem descriptografar, extrair conteúdo protegido ou executar scripts.
